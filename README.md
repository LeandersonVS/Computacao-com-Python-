    # Curso de Python


> **Observação:** Este material é referente ao curso *Introdução à Ciência da Computação com Python*, da Universidade de São Paulo (USP). O curso apresenta conceitos introdutórios de Ciência da Computação e programação em Python, sem exigir experiência prévia. Por meio de pequenos programas, busca desenvolver o raciocínio aplicado à resolução de problemas computacionais. É recomendado ter conhecimentos básicos de matemática do ensino fundamental.


Este arquivo reúne um resumo dos arquivos de exercícios e exemplos que estão nesta pasta.

## Exercícios e exemplos

- **Bhaskara.py** — calcula o discriminante de uma equação do segundo grau e exibe as raízes reais, quando existirem.
- **Cartão.py** — pede nome, vencimento e valor de uma fatura e monta uma mensagem para o cliente.
- **Condicao.py** — demonstra o uso de condições `if` e `else` com uma situação de decolagem.
- **Contasegundos.py** — converte uma quantidade de segundos em dias, horas, minutos e segundos.
- **Desafio da videoaula.py** — calcula as raízes reais de uma equação do segundo grau a partir dos coeficientes informados.
- **Distância entre dois pontos.py** — calcula a distância entre dois pontos e informa se ela é “perto” ou “longe”.
- **Exercicio2.py** — lê um número e imprime os primeiros números ímpares positivos até a quantidade indicada.
- **Exercicio3.py** — calcula a soma dos dígitos de um número inteiro.
- **Exercício 1 - Máximo.py** — define a função `maximo`, que retorna o maior de dois números.
- **Exercício 1 - Removendo elementos repetidos.py** — define `remove_repetidos`, que ordena uma lista de números e remove elementos duplicados; também permite digitar a lista.
- **Exercício 1.py** — calcula o fatorial de um número inteiro não negativo.
- **Exercício 2 - Primos.py** — define `maior_primo`, que encontra o maior número primo menor ou igual ao número informado.
- **Exercício 2 - Soma dos elementos de uma lista.py** — define `soma_elementos`, que soma os números de uma lista digitada.
- **Exercício 3 - Vogais.py** — define `vogal`, que verifica se o caractere informado é uma vogal.
- **FizzBuzz parcial, parte.py** — imprime “Fizz” quando o número digitado é divisível por 3.
- **FizzBuzz parcial, parte 2.py** — imprime “Buzz” quando o número digitado é divisível por 5.
- **FizzBuzz parcial, parte 3.py** — imprime “FizzBuzz” quando o número digitado é divisível por 3 e por 5.
- **Jogo do NIM.py** — implementa o jogo do NIM contra o computador, com opção de partida única ou campeonato.
- **Lista.py** — mantém uma lista de 30 frutas, conta quantas vezes cada tipo aparece e permite consultar uma fruta.
- **Media.py** — calcula a média aritmética de quatro notas informadas.
- **numerosinteiros.py** — identifica e imprime o algarismo das dezenas de um número inteiro.
- **Par.impar.py** — verifica se um número inteiro é par ou ímpar.
- **Perimetro-area.py** — calcula o perímetro e a área de um quadrado a partir do lado.
- **Retangulo_1.py** — imprime um retângulo preenchido com caracteres `#`, usando a largura e a altura informadas.
- **Retangulo_2.py** — imprime um retângulo vazado com caracteres `#` na borda e espaços no interior.
- **Similaridades entre textos.py** — calcula características linguísticas de textos e identifica qual deles tem a assinatura mais parecida com a informada.
- **Teste.py** — define uma função iterativa para calcular o fatorial de um número.
- **test_teste.py** — contém testes automatizados para a função `fatorial` de `Teste.py`.
- **Verificando ordenação.py** — verifica se três números informados estão em ordem crescente.


Curso realizado na plataforma Coursera.
